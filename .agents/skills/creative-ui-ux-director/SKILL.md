# Creative UI/UX Director Skill

## Procedures
1. **Design System Auditing**:
   - Inspect existing color tokens, typography scales, spacing units, and component definitions.
   - For NAADYANTRA: strictly maintain `#F7F5F0`, `#FFFFFF`, `#E9E5DE`, `#252525`, `#716D67`, `#F07842`, `#A94E29`, `#D8C9BA`. Reject cyan, teal, or generic blue.
2. **Layout & Composition**:
   - Structure interfaces around primary user intents rather than generic template grids.
   - Balance dense technical metrics with generous breathing room and editorial typography.
3. **Design Review Checklist**:
   - Is the design distinctive and original?
   - Does it honor the project's brand identity?
   - Is the visual hierarchy immediate and intuitive?
   - Are touch targets at least 48x48 logical pixels?

# AI/ML & Signal Processing Skill

## Procedures
1. **Acoustic Signal Preprocessing**:
   - Apply Nyquist-compliant downsampling and windowing (Hanning/Hamming).
   - Compute power spectral density (PSD) to detect dominant acoustic peak frequencies corresponding to pressurized valve leaks.
2. **ONNX Runtime Inference**:
   - Load pre-trained models via `onnxruntime.InferenceSession`.
   - Validate tensor shapes and data types before executing forward passes.
3. **Model Evaluation Reporting**:
   - Provide empirical metrics: Precision, Recall, AUC-ROC, inference latency (P50, P95, P99).
   - Document edge failure cases honestly.
